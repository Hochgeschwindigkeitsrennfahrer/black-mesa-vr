Black Mesa VR — drop-in test (2026-09-21)
==========================================

Close Black Mesa first. Copy this folder into Steam\steamapps\common\Black Mesa
so d3d9.dll lands in ALL three:

  Black Mesa\d3d9.dll
  Black Mesa\bin\d3d9.dll
  Black Mesa\bin\thirdparty\dxvk-windows-x86\d3d9.dll

Keep a tuned VR\config.txt if you already have one.

This build
----------
Alt-tab audio safety check. Tab-out still mutes as usual. About 1.5 seconds
after tabbing back in, the mod only acts if sound is still stuck:

- Windows session still muted, or its volume collapsed
- playback device changed and the meter is still silent (one snd_restart)
- the mix buffer was playing and is now lost or stopped

If audio already came back, nothing is changed. A repair writes a log line
starting with "Audio focus:".
