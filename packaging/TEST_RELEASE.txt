Black Mesa VR — drop-in (2026-09-08)
====================================

Close Black Mesa first. Copy this folder into Steam\steamapps\common\Black Mesa
so d3d9.dll lands in ALL three:

  Black Mesa\d3d9.dll
  Black Mesa\bin\d3d9.dll
  Black Mesa\bin\thirdparty\dxvk-windows-x86\d3d9.dll

Keep a tuned VR\config.txt if you already have one. If you keep the old
config, add these lines (or the DLL defaults apply):

  MulticoreMode=true
  VrHandsIndexRollDeg=90
  OpenXRHelperFlipSubmitY=false

This build
----------
- Multicore rendering — expect massive performance upgrades
- SteamVR submit Y-flip off by default (was inverted with auto)
- Quest Horizon Link no longer freezes after multicore
- Fixed lens flare positions
- Fixed inability to attack after grabbing / using something with the left hand
- Fixed Valve Index hand / weapon poses
- Fixed missing binds on some controllers

If shots misalign with the weapon position, recenter by pressing the right
thumbstick once. Roomscale support is coming.
